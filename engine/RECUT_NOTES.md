# Cut format (from Nov 27, 2026 on)
Every new video uses these defaults (transform.py applies them to a spec):
- Cold open: 0.9 s flash-forward of the craziest shot with the bold question on screen (spec `cold: 0.9`).
- Bold title: Archivo Black, white + yellow highlight, black outline (web/lib.js bigTitle).
- Only 3 narrated escalation beats; the rest are quick 0.6 s flashes.
- Narrator speed 1.2; tail 0.12 s; ends on "So never ask:" so it loops into the opening question.
- Target length 36-42 s.
Posting: no hashtags in titles, #fyp added to captions, YouTube + Instagram + TikTok, first comment = the caption's question, cover at 400 ms.
